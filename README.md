# 다육이 소원 공작소 — GitHub 공유 재고 버전

아이들이 질문 4개에 답하면 다육이 5종(수, 애플캔디, 어메이징그레이스, 엘린, 미니염좌, 각 40개) 중 하나를 추천하는 앱이에요.
모든 태블릿이 **구글 시트 하나**로 재고를 함께 써요. 다 떨어진 다육이는 어느 태블릿에서도 추천되지 않아요.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 아이들이 쓰는 앱 (GitHub Pages에 올려요) |
| `Code.gs` | 구글 시트에 붙이는 재고 서버 스크립트 |
| `care.html` | 부모님용 다육이 돌봄 안내 (결과 화면 QR로 열려요) |
| `qrcode.js` | QR 코드를 그리는 라이브러리 (MIT, Kazuhiko Arase) |
| `README.md` | 이 안내서 |

---

## 1단계. 구글 시트에 스크립트 붙이기 (약 5분, 한 번만)

1. 기록용 구글 시트를 열어요.
   이미 만들어 둔 시트: <https://docs.google.com/spreadsheets/d/1YWLHve102VGwq-bHA8ejAs8xRBYg8sd8d_VN-lWTuLs/edit>
2. 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
3. 원래 있던 코드를 모두 지우고, `Code.gs` 내용을 통째로 붙여 넣은 뒤 **저장(💾)**을 눌러요.
4. 오른쪽 위 **배포 → 새 배포**를 눌러요.
   - 유형 선택(⚙️) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 눌러요.
5. 권한 승인 창이 뜨면 내 구글 계정을 고르고 허용해요.
   "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르면 돼요. 내가 만든 스크립트라서 나오는 안내예요.
6. **웹 앱 URL**(끝이 `/exec`)을 복사해요.
   이 주소를 브라우저에서 열었을 때 `다육이 재고 서버가 켜져 있어요. (OK)`가 보이면 성공이에요.

> 시트에 **기록**, **설정** 탭이 자동으로 생기고, **재고 현황** 탭이 자동으로 채워져요.
> 예전에 만든 **추천 기록** 탭은 더 이상 쓰지 않으니 지워도 돼요.

## 2단계. index.html에 주소 넣기

`index.html`을 열어 `CONFIG` 부분을 찾고, `SCRIPT_URL`에 복사한 주소를 넣어요.

```js
const CONFIG = {
  SCRIPT_URL: "https://script.google.com/macros/s/……/exec",   // ← 여기
  APP_KEY: "dayuk-2026",                                      // Code.gs의 APP_KEY와 같아야 해요
  SHEET_URL: "https://docs.google.com/spreadsheets/d/……/edit" // (선택) 선생님 메뉴의 '시트 열기' 링크
};
```

`SCRIPT_URL`이 비어 있으면, 시트 없이 **그 기기 안에서만** 세는 체험 모드로 동작해요. 이때 제목 옆에 "이 기기만" 표시가 떠요.

## 3단계. GitHub에 올리기

1. GitHub에서 **New repository**를 만들어요. 예: `dayuk-app` (Public)
2. **Add file → Upload files**로 `index.html`, `care.html`, `qrcode.js`를 함께 올리고 **Commit changes**를 눌러요.
3. **Settings → Pages**에서 Branch를 **main / (root)**로 고르고 **Save**를 눌러요.
4. 1~2분 뒤 `https://내아이디.github.io/dayuk-app/` 주소로 앱이 열려요.

## 4단계. 각 태블릿 준비 (8대 + 관리용)

로그인은 필요 없어요. 앱 주소만 열면 돼요.

| 기기 | 홈 화면에 추가 |
|---|---|
| 아이패드 (사파리) | 공유 버튼 → 홈 화면에 추가 |
| 삼성 패드 (삼성 인터넷) | 메뉴(≡) → 현재 페이지 추가 → 홈 화면 |
| 삼성 패드 (크롬) | ⋮ → 홈 화면에 추가 |
| 크롬북 / PC 크롬 | ⋮ → 전송, 저장, 공유 → 바로가기 만들기 → "창으로 열기" 체크 |

- 첫 화면에 **시작하기!** 버튼이 보이면 연결된 거예요.
  "구글 시트와 연결되지 않았어요"가 보이면 인터넷과 `SCRIPT_URL`을 확인해 주세요.
- 선생님 메뉴(261017) → **구글 시트 연결**에 "모든 패드가 구글 시트 하나로 재고를 함께 써요"가 보이면 정상이에요.
- 자동 잠금은 "안 함"으로 바꿔 두세요. 아이패드는 사용법 유도 접근, 삼성 패드는 앱 고정을 켜 두면 좋아요.

## 5단계. 행사 직전

1. 선생님 메뉴 → **재고 초기화**를 눌러요.
2. 5종 모두 **40개**인지, 구글 시트 **재고 현황** 탭에도 40개씩 보이는지 확인해요.
3. 한 대에서 끝까지 해 보고, 다른 태블릿의 선생님 메뉴에서 1개 줄었는지 확인해요. 다른 태블릿에는 15초 안에 반영돼요.

## 행사 중

- 시작하기 → 이야기(건너뛰기 가능) → 질문 4개 → 결과 화면의 **노란 표시에 나온 품종**을 건네요.
- 결과 화면의 **QR 코드**를 부모님 휴대폰 카메라로 찍으면, 받은 품종이 맨 위에 나오는 돌봄 안내(`care.html`)가 열려요. 그 화면을 캡처해 두시면 돼요.
- **선생님 확인 받기 → 568**을 누르면 다음 아이 차례예요.
- 화분을 못 받아 갔으면 선생님 메뉴 → "방금 추천 하나 취소하기"를 눌러요.
- 실제 개수와 다르면 선생님 메뉴 → "남은 개수 직접 맞추기"로 고쳐요.

## 알아 둘 점

- **동시에 눌러도 안전해요.** 추천은 구글 시트 스크립트가 한 번에 하나씩 처리하고, 처리하는 순간 남은 개수를 다시 세요. 마지막 1개를 두 아이에게 주지 않아요.
- **인터넷이 잠깐 끊겨도 두 번 빠지지 않아요.** "다시 해 보기"를 눌러도 같은 요청으로 처리돼요.
- **결과까지 1~3초 걸려요.** 구글 스크립트가 응답하는 시간이에요. 그동안 요정이 찾는 화면이 보여요.
- **스크립트를 고친 뒤에는** 배포 → 배포 관리 → ✏️ → 버전: **새 버전** → 배포를 눌러요. 그래야 주소가 바뀌지 않아요.
- **보안:** 앱 주소와 `APP_KEY`, 번호(568, 261017)는 페이지 코드를 열면 보여요. 앱 주소는 행사 선생님들끼리만 나눠 주세요. 아이 개인정보는 저장하지 않아요.
